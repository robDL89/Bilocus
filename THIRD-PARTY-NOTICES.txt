1. Revit add-in for Revit 2024 (net48 build)
--------------------------------------------

System.Text.Json. The add-in therefore ships these Microsoft libraries next
to Bilocus.Revit.dll. They are unmodified, taken from their official NuGet
packages:

2. Revit add-in for Revit 2025 (net8.0-windows build)
-----------------------------------------------------

No third-party libraries are redistributed: System.Text.Json is part of
.NET 8, which Revit 2025 provides.


3. Autodesk Revit API
---------------------

RevitAPI.dll and RevitAPIUI.dll are used only as compile-time references
(through the Nice3point.Revit.Api.RevitAPI and .RevitAPIUI NuGet packages).
They are NOT redistributed: at run time the add-in uses the copies installed
with Autodesk Revit software.


4. Blender add-on
-----------------

The Blender add-on uses only the Python standard library and the Blender
Python API (bpy) provided by Blender at run time. No third-party code is
redistributed.
